# Swaddlely Feedback

Public, reviewed bugs and feature requests for [Swaddlely](https://swaddlely.com).

This repository contains no application source code. Swaddlely's code and private support reports remain private.

## Get help privately
In Swaddlely, open **Settings > Help & feedback** to report a problem, request a feature or ask for help. You do not need a GitHub account to submit in the app.

Do not post passwords, account details, names, photos, or information about a child or household in public issues. Report urgent care concerns to an appropriate professional, not this tracker.

## Public issues
The maintainer publishes reviewed, sanitized summaries here. Raw in-app support requests are never automatically published. Public issues and comments can be seen by anyone; avoid personal information.

Browse the [issue tracker](https://github.com/mylesdc/swaddlely-feedback/issues).
